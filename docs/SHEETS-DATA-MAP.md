## ไม่ขึ้น Sheets (เก็บในเครื่องเท่านั้น)
ร่างฟอร์มที่ยังไม่บันทึกเคส · ประวัติการแก้ไข (audit log) · PIN/ผู้ใช้/ตั้งค่าซิงก์ · เครื่องคำนวณ M-01 ถึง M-04 (ไม่เก็บข้อมูลผู้ป่วย)

## ที่เทสต์ยืนยันแล้ว
- ข้อมูลทุกชุดไปถึงเครื่องอื่นเท่าเดิม ยกเว้นชื่อ/HN ที่ปกปิดตามออกแบบ (รวมข้อความพิเศษ เครื่องหมายคำพูด ขึ้นบรรทัดใหม่ อีโมจิ)
- ไม่มีชื่อผู้ป่วยหรือ HN ดิบในเซลล์ใดของชีต
- ข้อความที่ขึ้นต้นด้วย `= + - @` ไม่ถูกตีความเป็นสูตร (ใส่ `'` นำหน้า)
- ลบในแอป → แถวในชีตถูกล้างข้อมูลทางคลินิก
- รายการที่ใหญ่เกิน 50,000 ตัวอักษรต่อเซลล์ไม่ขวางรายการอื่น และแจ้งผู้ใช้

## ข้อจำกัดที่ทราบ
- **เคสซ้ำข้ามเครื่อง:** แอปใช้ชื่อ+HN จับว่าเป็นเคสเดียวกัน แต่เครื่องอื่นไม่มีชื่อ (ปกปิด) ถ้าบันทึกผู้ป่วยรายเดียวกันจากสองเครื่อง อาจได้ 2 เคส ทำให้ตัวชี้วัดนับซ้ำ → ตกลงว่าใครบันทึกเคสเดียวกัน หรือรอการแก้ไข (จับด้วย HN hash)
- **แก้พร้อมกัน:** ระดับทั้งรายการ ฉบับล่าสุดชนะ ไม่รวมรายฟิลด์
- **ประวัติเวอร์ชันของ Google Sheets** ยังเก็บค่าเก่าหลังลบ — การลบตามอายุข้อมูลต้องจัดการประวัติเวอร์ชัน/ถังขยะของไฟล์ด้วย
- ผู้ที่มีสิทธิ์แก้ไขชีตแก้คอลัมน์ข้อมูลเต็มได้ และแอปจะรับค่านั้นเมื่อซิงก์ — ให้สิทธิ์แก้ไขเฉพาะผู้ดูแล

## หน้าตาของชีต (Code.gs เวอร์ชันล่าสุด)
- ความกว้างคอลัมน์ตามชนิดเนื้อหา (ข้อความยาว 300–440 · ค่าสั้น/ตัวเลข 95) ตัวอักษรขึ้นบรรทัดใหม่เอง ล็อกแถวหัวและ 2 คอลัมน์แรก มีตัวกรอง
- สีสถานะ: รอส่ง HPVC / ป้องกันได้ / RCA ยังไม่ครบ / ยังไม่รายงาน med error = เหลือง · ส่งแล้ว / ทำครบ / รายงานแล้ว / ดำเนินการแล้ว = เขียว · เคสรุนแรง / แพ้ยาซ้ำ / Serious / พบ ADR = แดง
- เลื่อนเมาส์ที่หัวคอลัมน์สำคัญเพื่ออ่านคำอธิบาย (โน้ตที่หัวคอลัมน์)
- เรียงใหม่สุดไว้บน และรายการที่ลบแล้วไว้ล่างสุด (วันที่เป็นข้อความไทย จึงเรียงเองด้วยตัวกรองตามวันที่ไม่ได้ — ใช้ลำดับเริ่มต้นของแท็บ)
- ส่งข้อมูลจำนวนมากเป็นชุดเดียว (ส่งทั้งหมดใหม่ 1,000 เคสไม่ช้า)

## ข้อควรระวัง
- แอปเก็บเคสสูงสุด 1,000 เคส (ข้อจำกัดเดิมของต้นแบบ) ถ้าเกิน เคสเก่าสุดจะถูกตัดออกจากแอปและ **ถูกลบในชีตด้วย** — ควรสำรองข้อมูลและส่งออกก่อนถึงจำนวนนี้
- ถ้าเคยใช้ชีตเวอร์ชันก่อนหน้า คอลัมน์ใหม่จะถูกเพิ่มต่อท้าย (ก่อน "ลบแล้ว?") เพื่อให้ลำดับสวยที่สุด ให้ลบแท็บข้อมูลเดิมแล้วกด "ส่งข้อมูลทั้งหมดใหม่" ในแอป
