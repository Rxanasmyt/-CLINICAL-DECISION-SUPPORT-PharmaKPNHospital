# เอกสารตรวจสอบสูตรคำนวณทางคลินิก (สูตรเวอร์ชัน F1)

สร้างอัตโนมัติจากโค้ดด้วย `npx vite-node tools/validation-sheet.ts` — **อย่าแก้ตารางผลลัพธ์ด้วยมือ**

## วิธีใช้
1. เภสัชกรผู้เชี่ยวชาญแต่ละด้านเทียบ "ผลที่แอปคำนวณ" กับแนวทางอ้างอิงล่าสุดและรายการยา/ความแรงที่ รพ. มีจริง
2. ทำเครื่องหมายผ่าน/ไม่ผ่านในคอลัมน์สุดท้าย (พิมพ์เอกสารนี้หรือคัดลอกลง Excel) ข้อที่ไม่ผ่านให้แจ้งผู้พัฒนาพร้อมเหตุผลและแหล่งอ้างอิง
3. เมื่อผ่านทุกข้อของหัวข้อใด ให้ลงนามท้ายเอกสาร แล้วแก้ `src/data/validation.ts` (status = approved, reviewer, reviewedAt) ผ่าน Pull Request
4. ทุกครั้งที่แก้สูตร ให้สร้างเอกสารนี้ใหม่ เพิ่มเลขสูตรเวอร์ชัน และตรวจซ้ำเฉพาะส่วนที่เปลี่ยน
