# แผนทดลองใช้คู่กับวิธีเดิม (1–2 เดือน) ก่อนพึ่งพาแอปจริง

แอปเป็นเครื่องมือช่วยตัดสินใจ ไม่ทดแทนดุลยพินิจของเภสัชกร ช่วงทดลองให้ทำงานด้วยวิธีเดิมตามปกติ แล้วใช้แอปคู่ขนานและเทียบผล

## เงื่อนไขก่อนเริ่ม
- [ ] เภสัชกรผู้เชี่ยวชาญตรวจสูตรตาม `docs/CLINICAL-VALIDATION.md` และลงนามครบหัวข้อที่จะใช้ (ยังไม่ครบ = ห้ามใช้หัวข้อนั้นกับผู้ป่วยจริง)
- [ ] ตั้ง PIN และชื่อผู้ใช้ในเครื่องที่ใช้ (ปุ่ม 🔒 ความปลอดภัย) และเปิดการเข้ารหัสดิสก์ของเครื่อง
- [ ] ผ่าน `docs/PDPA-CHECKLIST.md` ก่อนเปิดซิงก์ Google Sheets (ถ้าไม่ผ่าน ใช้ในเครื่องอย่างเดียวและสำรองไฟล์เอง)
- [ ] กำหนดผู้รับผิดชอบแอป 1 คน (รับแจ้งปัญหา ตัดสินใจแก้สูตร)

## ระหว่างทดลอง
- ทุกเคสที่ใช้เครื่องคำนวณ: เภสัชกรอีกคนตรวจผลซ้ำด้วยวิธีเดิม (double-check) แล้วบันทึกในตารางด้านล่าง
- ผลต่างกัน = ถือเป็นเหตุการณ์ต้องทบทวน: ถ่ายภาพหน้าจอ บันทึกข้อมูลที่ป้อน แจ้งผู้รับผิดชอบแอปภายในวันเดียวกัน
- สำรองข้อมูลทุกสัปดาห์ (แอปเตือนเมื่อเกิน 7 วัน)
- ตรวจประวัติการแก้ไข (ปุ่ม 🔒 → ประวัติ) สัปดาห์ละครั้งว่ามีรายการผิดปกติหรือไม่

## เกณฑ์ผ่านการทดลอง (กำหนดร่วมกับกลุ่มงานก่อนเริ่ม ตัวอย่าง)
- ไม่พบผลต่างที่ส่งผลต่อความปลอดภัยผู้ป่วยตลอดช่วงทดลอง และทุกผลต่างได้รับการทบทวนและแก้ไขแล้ว
- มีจำนวนเคสเทียบเพียงพอในแต่ละโมดูลตามที่กลุ่มงานกำหนด
- เภสัชกรผู้ใช้ทุกคนผ่านการอบรมใช้แอปและรู้ข้อจำกัด
- ผู้บริหารกลุ่มงานลงนามอนุมัติใช้จริง
